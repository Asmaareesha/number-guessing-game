# Number Guessing Game

A simple command-line game written in Python. The computer picks a random
number between 1 and 100, and you keep guessing until you get it right.
After each guess, it tells you whether to go higher or lower.

## How to run it

1. Install Python from python.org
2. Download guess.py
3. Open a terminal in the same folder and run: python guess.py

## What I learned

Using loops, if/else statements, user input, and the random module.
